# Agent briefs

Ready-to-paste task prompts for agents working one track each
(`docs/workstreams.md`). Give an agent `_common.md` followed by one track
file, in its own git worktree checked out from `main`. Before starting a
track, check that nobody else is on it: open PRs (`gh pr list`) and
`docs/workstreams.md`.

| file | track | status when written (2026-10-28) |
|---|---|---|
| `perf-vm.md` | the VM and the JIT | free |
| `conformance-strings.md` | string builtins | free |
| `conformance-vectors.md` | vectors, subsetting, sorting | free |
| `conformance-lang.md` | language, environments, conditions | free |
| `conformance-print.md` | printing, formatting, deparsing | free |
