## 2026-11-13: N1a, symbols, globals and hashed environments (`robigo-rtcore`)

- What: GNU R 4.6.2's `envir.c` on the isolate (m1-plan §B N1a; docs/g3.md
  §5.2-5.3; council Fable round 2 §3.1-3.2). New in `robigo-rtcore`:
  `sym.rs` (symbol ids and the per-isolate symbol cells), `env/mod.rs`
  (the environments' state, the entry points), `env/hashtab.rs` (GNU R's
  hashed frames), `env/chain.rs` (chains of binding cells), `env/frame.rs`
  (unhashed frames). Ported, each marked `// R: envir.c:...`: `defineVar`,
  `gsetVar`, `setVar`/`setVarInFrame`, `findVarInFrame3`,
  `R_existsVarInFrame`, `findVar`/`findVarLoc`, `findGlobalVarLoc` and the
  global cache, `findFun3` (its messages verbatim), `RemoveVariable`,
  `R_removeVarFromFrame`, `unbindVar`, `R_lsInternal3` (unsorted),
  `R_envSymbols`, `R_HashProfile`, `R_LockEnvironment`,
  `R_EnvironmentIsLocked`, `R_LockBinding`, `R_unLockBinding`,
  `R_BindingIsLocked`, `R_BindingIsActive`, `R_MakeActiveBinding`,
  `R_ActiveBindingFunction`, `do_mkUnbound`, `getActiveValue`,
  `setActiveValue`, `R_NewEnv`/`R_NewHashedEnv`, `InitBaseEnv`,
  `InitGlobalEnv`, names.c's `Spec_name`. On the heap: a symbol's id and
  `R_Newhashpjw` of its name.
- Decisions, each where g3.md or the foreman left a choice:
  - **Symbol ids live in the symbol** (foreman's answer 1: the shared arena
    is M2). The heap gives every symbol a dense id in the order it made
    them and stores it with GNU R's `R_Newhashpjw` of the name in the
    symbol's 4th word (`OFF_SYMID`: id low, hash high; one load for both).
    The SYMSXP trace arm stops at INTERNAL (+32). `install` also sets GNU
    R's `HASHASH`/`HASHVALUE` on the PRINTNAME, as names.c does (the
    oracle's `inspect` shows `gp=0x61` on a symbol's name, `0x60` on
    another string). `R_Newhashpjw` takes each byte as
    C's `char` (signed on x86-64, unsigned on aarch64), as GNU R does: the
    oracle's bucket positions for `é`, `ü`, `aéb`, `中文` confirm it. Every
    use of an id or hash goes through `sym.rs` (`id_of`, `hash_of`,
    `for_each_installed`); M2's arena replaces those three and nothing else.
  - **Per-isolate symbol cells** (`SymCells`, indexed by id, growing on
    demand since M2's other isolates install symbols this one has not
    seen): per symbol the base binding's value (GNU R's `SYMVALUE`), its
    bits (`ACTIVE_BINDING`, `BINDING_LOCK`, `ASSIGNMENT_PENDING`, which GNU R
    keeps on the symbol's gp) and the symbol's **global cache entry**, one
    word: null, the symbol itself (GNU R's `BASE_SYM_CACHED`: a hit costs no
    second load) or a binding cell of a global frame. 24 bytes, one cache
    line per lookup. GNU R's `R_GlobalCache` hash table goes; its flush
    points are GNU R's (define and remove in a global frame, `gsetVar`,
    `mkUnbound`, attach and detach). As in GNU R, `SET_ENCLOS` does not
    flush it. What stays on the symbol never changes: name, hash, id and
    `SPECIAL_SYMBOL`.
  - **Hashed frames are GNU R's representation**: FRAME R_NilValue, HASHTAB
    a VECSXP of chains of LISTSXP binding cells, `HASHPRI` its TRUELENGTH,
    `R_HashResize` relinking each chain head-first. Two quirks are kept
    because `env.profile()` and the resize points show them, and the oracle
    confirms both: `R_HashSet` counts every new binding into `HASHPRI` (its
    `ISNULL(chain)` reads the loop variable after the loop), and
    `R_HashDelete` uncounts only a chain that empties (`C24`: 24 bindings in
    19 chains report `nchains 24`; the table grows at the 25th insertion).
  - **Unhashed frames keep GNU R's pairlist behind `frame.rs`**, the one
    interface N1b's slot frames replace (find, new cell's link, push,
    remove, walk). This is also X1's D2 control. Nothing outside `frame.rs`
    reads an unhashed frame's words.
  - **A binding's location is one word** (`Loc`), as GNU R's
    `R_varloc_t.cell`: a cell, or for base the symbol, told apart by type.
    A lookup's `Result<Option<Loc>, _>` then comes back in two registers;
    the first version's two-word enum went through memory (146 against 104
    instructions for a cache hit, below).
  - **Versions**: a frame's version box is an INTSXP of one element in the
    ENVSXP's 4th word (+40), made on first request
    (`cx.env_version_box`); `fn_version` moves when a binding that holds or
    held a function-like value (closure, builtin, special, promise,
    `R_MissingArg`) or an active binding is created, changed or removed, or
    ENCLOS changes. A frame nobody asked about has no box and pays nothing.
    `search_epoch` (in the isolate) moves for such changes in global frames
    and base, and when a frame becomes global or local. Memos hold the box,
    never an address (§5.3).
  - **The evaluator is a hook** (`cx.set_eval`, `cx.eval`): active bindings
    (`getActiveValue`, `setActiveValue`) and `findFun3`'s promises run R
    code, and the evaluator (V1, C1) lives above this crate. With none
    registered the call is an error that says so.
  - **`FIX_BINDING_REFCNT`** is ported in the one binding store: while a
    cell's (or base binding's) `ASSIGNMENT_PENDING` is set, the store keeps
    the old value's count and clears the bit. C1's complex assignment sets
    it.
  - **R_NilValue on a chain** (the namespace registry's ENCLOS, as GNU R
    makes it) stops a walk with "use of NULL environment is defunct", as
    `findVarInFrame3` does in GNU R's `findVar` and `findFun3` (oracle:
    `get("zzz_q", envir = <registry>)`). GNU R's `setVar` loops forever
    there (`ENCLOS(R_NilValue)` is itself); robigo reports the same error.
  - **Not here, each raising "robigo: ... not implemented yet"**: user
    database environments (`R_ObjectTable`), environments that are S4
    objects (their `inherits()` needs methods). Typed binding cells
    (`BNDCELL_TAG`) are not made (unboxed values are N1b's slots).
- Left to others, at one place each: `error()`'s context call (C2:
  `env_error`), `PROMISE_TAG` (C1: `promise_value`), `EncodeChar`'s
  escaping of unprintable names (the text layer: `sym_name`), the sorted
  half of `R_lsInternal3` (`sortVector` with `Scollate`: the string
  layer), the condition classes of `R_MissingArgError` (S1). The `do_*`
  builtins (`assign`, `get`, `exists`, `mget`, `ls`, `env.profile`,
  `lockBinding`, ...) are B1's over these entry points; `attach`/`detach`
  get `mark_global_frame`/`mark_local_frame` and `set_enclos`.
- R1a's shared files, additive only: `Roots` gains the environments' state
  (traced; `for_each_root` lists it, and `roots_are_exactly_the_live_object_slots`
  compares against the isolate's own roots), `OwnedIsolate::with_options`
  makes it, `lib.rs` declares the modules.
- Proof (WSL2 workstation, Ryzen 9 5900X, 24 threads, rustc 1.100.0; GNU R
  4.6.2 from the oracle image via `~/.cache/robigo-oracle/4.6.2/bin/Rscript`,
  never the host's 4.6.1):
  - `tests/env.rs`, 14 tests. Three replay R scripts step by step against
    their recorded output, checked in under `tests/oracle/`
    (`envir-order.R`: `ls(sorted = FALSE)` and `env.profile()` of hashed and
    unhashed environments after inserts, `rm` and reinsertion, growth,
    dot names, non-ASCII names, `size = 5/0/NA`, collisions, the global
    environment, `list2env`; `envir-errors.R`: 19 messages; `envir-base.R`:
    base's listing order, two symbols sharing symbol-table chain 25405
    listed newest first). The others: argument checks, `findVar`/`setVar`
    through enclosures and the global cache, attached frames, `findFun3`
    skipping values and forcing promises, locks (values marked not mutable,
    base and its namespace sharing bindings), versions, `R_envSymbols`, the
    registry's NULL enclosure, `ASSIGNMENT_PENDING`, and collections.
  - Heap: `symbols_carry_an_id_and_gnu_rs_hash`; the SYMSXP row of
    `each_type_traces_exactly_its_pointer_words` is now `[8, 16, 24, 32]`.
  - `cargo test --release -p robigo-heap -p robigo-rtcore`, and the same
    under `ROBIGO_GCTORTURE=1`: all pass. Sensitivity: with the base
    values untraced (`#[trace(skip)]` on `SymCell::value`),
    `bindings_survive_collections` fails, with and without torture.
  - Miri (nightly 2026-10-27): `cargo +nightly miri test -p robigo-rtcore`,
    the env tests but the collecting one, no undefined behaviour (the
    heap's existing integer-to-pointer casts warn, as for R1a).
  - `cargo clippy -p robigo-heap -p robigo-rtcore -p robigo-rt --all-targets
    -D warnings`: clean.
  - R-level rt cases (`tests/rt/`) wait for `scripts/rt-conf.py`, which
    is not on main; the recorded scripts above become cases then.
- Cost, as a baseline for N1b, V1 and X1: instructions per operation,
  callgrind N = 10^5 against 2N, of the ignored test `env_op_cost` (each
  includes its loop's root binds and owner checks), release, at `5e0c1a03`:

  | op | instructions |
  |---|---|
  | `frame_binding` + read, hashed frame of 100 bindings | 110 |
  | `define_var` replacing a value there | 282 |
  | `var_binding` of a base binding from the global environment (cache hit) | 104 |
  | `find_fun3` through three one-binding unhashed frames to a base function | 326 |

  An unhashed frame costs about 39 of `find_fun3`'s instructions per
  frame (the classification compares and the chain walk), GNU R's shape;
  slot frames and V1's call-site caches replace that path.
