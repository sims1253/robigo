## 2026-11-16: D5 adopted: frame recycling on main

The lead's D5 decision (Max, 2026-11-16, in `2026-11-16-p1-reruns.md`):
adopt frame recycling, judged on real calls, since inlined calls leave no
frames to reuse. It reverses `2026-11-14-d5-decision.md` (`none`). This
entry is the PR that brings it to main, under the usual conditions: the
full rt-ci with both quarantine steps, Miri, the observer cases, and the
bars' rows before and after.

- What it does (the variant's design, `2026-11-14-d5-runs.md`): when a
  closure call returns, `args::apply` offers its frame to a per-isolate
  pool, one LIFO list per slot capacity (at most 32 slots, 64 frames a
  list). The offer comes after `R_CleanupEnvir`, `end_call` and the
  argument list's cleanup. A frame is pooled only when nothing can reach
  it:
  - REFCNT 0, and it is not the value returned;
  - no attributes, overflow block, version box or caller word;
  - no cell-backed or active slot;
  - neither `ESCAPED` nor `SEEN_BY_C`.

  The next frame of that capacity is a pooled one, rewritten, instead of
  an allocation. Reading a context's `cloenv` or `sysparent` as a value
  marks the frame `ESCAPED` (`environment()`, `parent.frame()`,
  `sys.frame()`, `UseMethod`, ...). The pool is weak: every collection
  empties it.
- How C reaches a frame. `SEEN_BY_C` is set only under
  `ROBIGO_GC_MOVE=1`, so in production it guards nothing. C reaches a
  frame only through a counted edge (a closure's environment, an
  enclosure, a binding) or through a value R code read from a context,
  which is `ESCAPED`. `R_PreserveObject` roots without a count, so it
  keeps a frame only together with one of those. The module doc says so,
  and a C entry point that ever hands out a context's frame must mark it.
- Admission at `060c20af`: `scripts/test-rt-ci.py` and `scripts/rt-ci.py`
  pass every step, both quarantine steps included (conformance 255/260,

  miri test -p robigo-rtcore`, `scripts/lint.sh` and `cargo fmt --check`

- Observer case: `tests/rt/env/recycle-observers.R`, recorded on GNU R
  4.6.2. It keeps frames through `environment()`, a closure made in the
  frame, a promise forced after the call returned, `parent.frame()`,
  `on.exit` and `<<-`, `assign()`, a list, `new.env(parent =)`, an
  attribute and an S3 method. Each is read after calls that would take a
  recycled frame of the same size. Recursion through real calls checks
  that reused frames keep every level's locals. The case passes with and
  without `ROBIGO_FRAME_QUARANTINE=1`. Switching the `ESCAPED` marking off
  (a temporary switch, not committed) changes nothing in it, as the D5
  runs' sensitivity check found. Every escape there is counted or is the
  call's own value, and no path in robigo-rt's base reaches the pool with
  only an uncounted reference.
