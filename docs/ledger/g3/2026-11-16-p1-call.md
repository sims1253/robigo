## 2026-11-16: P1 step 3, the call: the evaluator's state, the new frame's special-symbol mark, the closure's code

The third P1 family (base and bars: `2026-11-15-p1-base.md`; steps 1-2:
`2026-11-15-p1-frames.md`, `2026-11-16-p1-forced.md`). These are costs
every closure call pays in `args::apply` that do not depend on what the
call does.

- Base: `g3/p1-forced` at `2ae5dbf1` (step 2's measured binary; its data
  `data/2026-11-16-p1forced-2ae5dbf1/`). Change: branch `g3/p1-call` at
  `ae7dfe38` (`robigo-rtcore`, `robigo-rt`).
- What changes:
  - **The evaluator's state** (`prims::state`, read several times on
    every call) came out of the isolate through `Any::downcast_ref`, a
    dynamic `type_id` call and a 128-bit compare. `Isolate::set_ext` now
    records the state's `TypeId` and address beside the box, and `ext`
    compares and casts. `set_ext` swaps the new box in and records it
    before it drops the old one, so a destructor that panics leaves the
    record describing the installed state (test
    `a_panicking_old_state_leaves_the_new_one_installed`; not on any
    measured path).
  - **The new frame's `NO_SPECIAL_SYMBOLS`**. `applyClosure` asks
    `R_envHasNoSpecialSymbols` of every new frame, which walked its bound
    slots. `new_closure_frame` now answers it while binding the formals, the
    only bindings a fresh frame has, and sets the flag. The shape's
    per-slot symbol check is a debug assertion (`make_shape` builds every
    shape from symbols).
  - **The closure's code**. `call::closure_code`'s common case returns the
    code at once, as `closure_profile` and the code check would find it: no
    forced profile, byte code enabled, and a compiled closure whose `Bc`
    code for its formals is attached. The end of a call that made early
    values is an inlined function, no longer a closure called through a
    pointer.
- Admission: `scripts/rt-ci.py` passes at `ae7dfe38` (exit 0): every
  step, conformance 212/217 (the base's 5 unratcheted failures).
  `scripts/lint.sh` and `cargo fmt --check` pass.
- Commands as in step 2 (`rt-bars.sh` twice, `s3` three more times,
  `rt-bars-compare.py --a forced ... --b call ...`).
- Raw JSON: `data/2026-11-16-p1call-ae7dfe38/run{1,2}-*.json`,
