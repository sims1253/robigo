## 2026-11-16: P1 step 6, pure-closure inlining: a compiled caller runs a pure closure's body inline

The sixth P1 family (base and bars: `2026-11-15-p1-base.md`; steps 1-5:
`2026-11-15-p1-frames.md`, `2026-11-16-p1-forced.md`,
`2026-11-16-p1-call.md`, `2026-11-16-p1-lookup.md`,
`2026-11-16-p1-unboxed.md`). This is the work list's pure-closure

- What changes (`crates/robigo-rt/src/inline.rs`):
  - **Which calls.** A call from byte code (`call::call`) of a compiled
    closure whose byte code qualifies runs the body inline: no frame,
    context or promise objects, its registers a local array. A body
    qualifies, once per code object and kept in its header's `inline`
    byte, when:
    - its frame shape is its formals (at most 4, no `...`, no locals);
    - it uses at most 16 registers;
    - it uses only constant loads, formal and enclosure reads, scalar
      arithmetic, comparisons and logic on the VM's fast paths, branches,
      the base-function guards, function lookups from the enclosure,
      calls, and `Ret`/`Return`.

    A closure whose attached byte code does not qualify gets the heap bit
    `extra::NO_INLINE`, so the hook rejects it with one test of the bits it
    already reads.
  - **Arguments.** Matched by exact name, then position, as `matchArgs`
    does without partial matches. A formal the call leaves out takes its
    default when that is a constant. Anything else gives up: a partial
    name, `...`, an empty argument, `*tmp*`, a computed default. A site
    whose arguments cannot be matched is memoized in its match plan
    (`Plan::no_inline`, keyed by the callee code's stamp). Arguments are
    forced lazily at the callee's first read:
    - an expression of the caller, through `early::early_force`'s counts,
      its value computed without running code (the early pass's reads, or
      compiled argument code over the pure subset);
    - a constant default as the real force makes it: the entry safepoint,
      `eval`'s count, `R_Visible`.
  - **Counts.** Kept as the real call keeps them: `evalcount` at each
    evaluation point, the depth checks, `bcEval`'s entry count,
    `R_Visible`. They are restored if the run gives up.
  - **Giving up.** The run gives up before anything observable, and the
    real call then runs from where the run began:
    - a count that would poll, or the depth limit;
    - a slow path: an error, a warning, a coercion;
    - a value it cannot read without running code (an unforced promise,
      an active binding, a force nested in another);
    - a call it cannot run inline, or calls nested deeper than 12;
    - a safepoint with work to do;
    - a debugged, traced or stepped closure.

    It allocates nothing and reaches no safepoint, so nothing collects
    while it holds raw objects.
  - `Cx::fun_lookup_from_raw` (rtcore) is the global-cache read that
    `fun_lookup_skip_raw` made, from the enclosure, and `Cx::safepoint_pending`
    asks whether a safepoint has work.

Checks of the conditions:
- **Condition 1.** Each give-up is listed above. The Rust tests
  (`crates/robigo-rt/tests/inline.rs`, sessions with GNU R's JIT
  decisions) run programs with inlining on and with `ROBIGO_NO_INLINE`'s
  switch off, and compare values, errors, `R_Visible`, `evalcount` and
  `bc_evalcount`:
  - over a set of programs (recursion, strings, defaults, logic, errors);
  - at every recursion depth under `expressions` 40 and 77, so the depth
    error falls at the same call;
  - with each of GNU R's bits 0-3 set on a closure, none of whose calls
    then runs inline.
- **Condition 2.** `tests/rt/inline/{values,observers,traceback}.R`,
  recorded on GNU R 4.6.2. Every case runs three times in a compiled
  top-level loop, so the last runs reach the hook, and each observer is
  also called through a pure wrapper, whose inline run gives up at the
  observer's call. They cover:
  - `sys.call`, `sys.function`, `parent.frame`, `match.call`, `on.exit`,
    `missing`, `substitute` and `environment()`;
  - errors and warnings with their calls;
  - the traceback of an error raised inside a chain of inlined calls;
  - redefinition of a callee, and of a nested callee, mid-loop;
  - laziness (an argument never forced, a forced side effect);
  - recursion.

  A temporary per-callee count confirmed that the wrappers' runs give up
  and the pure callees' run. Two observers are not R cases, because
  robigo-rt's base lacks them: `debug` (the debug-bit test above stands
  for it) and `options(expressions=)` (the depth test above).
- **Condition 3.** As admitted above.
