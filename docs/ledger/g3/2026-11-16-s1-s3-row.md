## 2026-11-16: S1, the `s3` row: a dispatch memo and less allocation (fixes 1 and 3 of `2026-11-16-p1-gaps.md`)

- What: the first two of the s3 row's planned fixes (`2026-11-16-p1-gaps.md`,
  "s3"), in `robigo-rt`'s `dispatch.rs`, and one read-only accessor in
  `robigo-rtcore`. Fixes 2 (the dispatch variables as slots of the method's
  frame) and 4 (dispatch from slot frames) touch X/P1's `args.rs` and
  `new_closure_frame` and wait for D5 (the foreman's ruling, 2026-11-16).
- Fix 1, the dispatch memo. `usemethod`'s methods are memoized by (generic,
  class vector, defining environment): `DispatchMemo` holds the symbols it
  tries (`installS3Signature`'s, class by class, then the default), so they
  are not built and installed per dispatch. Each is then looked up as
  `R_LookupMethod` does, without running code when it can (`quick_search`):
  - `topenv(R_NilValue, callrho)` once per dispatch, not per method (nothing
    in between runs code);
  - the frames from `callrho` below the top read directly; a binding that is
    a promise, an active binding or an argument slot not read yet sends the
    whole search to `lookup_method`, which forces or reads it as GNU R does;
  - the search from the top on through S1's version-validated memo
    (`memo_get`, unchanged).
  Invalidation follows what `R_LookupMethod` reads, not the benchmark: the
  calling frames are read every time (they are the calls' frames, new each
  call); the top environment and everything after it, and the defining
  environment's S3 methods table, are the memo's version boxes and its
  re-reads (§9.3); the class vector is a private copy compared element by
  element (CHARSXPs by identity), so no change to an object's class
  attribute reaches the key; the generic's environment chain enters through
  the defining environment, part of the key. A signature too long for
  `installS3Signature` is still an error where the search reaches it.
  Frames are passed over by their shape where that settles it
  (`Cx::slot_frame_shape`, its own commit): `topenv` skips a slot frame with
  no overflow block and no attributes whose shape has neither `.packageName`
  nor `.__NAMESPACE__.`, and an entry skips one whose shape has none of its
  methods; shapes never change, so the verdicts are remembered by the
  shape's identity.
- Fix 3, less allocation:
  - `dispatchMethod`'s `.Group` is `R_BlankScalarString` and `.Method`
    `ScalarString(PRINTNAME(method))`, as objects.c makes them (no `mkChar`);
    `NextMethod`'s blank group likewise; `.Generic` is the memo entry's
    `mkString(generic)`, marked not mutable (a method that changes its
    `.Generic` changes a copy: checked on 4.6.2);
  - `GetObject` walks `cptr->promargs` in place (exact matches by symbol
    identity, partial ones by name) instead of copying every tag's name;
  - `UseMethod`'s own arguments bind by position when untagged (one or two,
    none `...`), else `matchArgs_NR`;
  - `R_USEMETHOD_FORWARD_LOCALS` is still read where GNU R reads it (at the
    first generic with a local that is not a formal), but a generic's frame
    whose shape is its formals, with no overflow block, has no such local,
    so the frame is not listed per dispatch;
  - `DispatchOrEval`'s primitive is found by name once, not through
    `by_sym`'s `HashMap` per dispatch (the row's `DefaultHasher`).
