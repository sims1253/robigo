## 2026-11-17: R's console on stdin (L4)

- What: GNU R's own build runs each R step as `R_EXE`,
  `$(top_builddir)/bin/R --vanilla --no-echo`, with the script on stdin
  (src/library/*/Makefile.in). robigo-rt printed Rscript's usage when given
  neither a FILE nor `-e`. Now, as GNU R's front end does when stdin is not
  a terminal (`R_Interactive` is `R_isatty(0)`, unix/system.c), it reads
  stdin as the console, the way `--file=-` already did: the transcript
  echoes unless `--no-echo`, and the exit status is GNU R's. A terminal's
  interactive console is not ported, so robigo-rt still prints the usage
  there.
- The save action: non-interactive R without `--save`, `--no-save` or
  `--vanilla` stops with "Fatal error: you must specify '--save',
  '--no-save' or '--vanilla'" (stderr, status 2). `--no-echo` implies
  `--no-save` (R_common_command_line), and so does `-f FILE` with a FILE
  (`if (ifp && ...) SaveAction = SA_NOSAVE`, system.c:497); stdin does not.
  robigo-rt now checks it at the same point, after the options, so that
  `-f` of a missing file still reports the open error first.
