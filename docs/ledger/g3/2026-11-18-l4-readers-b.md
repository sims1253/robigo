## 2026-11-18: readDCF, scan, textConnection (L4, part b)

- **readDCF** (`connections/readers.rs`, dcf.c's do_readDCF), in full:
  - records, folding, `keep.white`, continuation lines, " ." lines, comment
    lines, and fields asked for or every field seen;
  - its two errors;
  - the connection opened and closed around it (closed on error too).

  dcf.c's five TRE patterns on bytes are written as the byte tests they
  are, one comment each naming its pattern. A line is a C string, cut at
  its first NUL.
- **scan** (`connections/scan.rs`, scan.c), for character data:
  - `scanchar` (comment character, `allowEscapes`) and both branches of
    `fillBuffer` (white space, a separator, quotes, `strip.white`);
  - `scanVector`, and `scanFrame` with `fill`, `flush`, `multi.line` and
    NULL columns;
  - `do_scan`'s argument checks and messages.

  The C quirks are kept: `strchr`'s match of 0, a pushed-back saved
  character on a connection left open, and the UTF-8 BOM. A `what` of
  another type (logical, integer, double, complex, raw; their items go
  through `R_strtod` and friends) and the console (`file = ""`) refuse
  with "not implemented yet". The build's calls are all text: tools'
  `Adobe_glyphs` and the `scan(text =, what = character())` calls.
- **textConnection** in mode "r" (connections.c's do_textconnection,
  newtext, text_fgetc): the strings in the encoding `type` asks for, each
  followed by a newline, already open. `text_fgetc` returns C's signed
  char, so a 0xFF byte reads as the end. Reads and writes through
  `con->read`/`write` are GNU R's null methods' errors. Output text
  connections (`open` "w"/"a") refuse.
- **`parse()` from a connection** reads a saved character and the pushback
  first, then a text connection through its `fgetc` (R_ParseConn reads
  `Rconn_fgetc`). This is PR (a)'s deferred Sol S1. Other connections keep
  their raw read, so a partial parse's give-back on a file still counts
  bytes.
- **`internalsID`** checks no arguments, as GNU R's does not (B's audit).
- Cases: `tests/rt/connections/{readdcf,scan,textconnection}.R` and
  `tests/rt/ns/internals-id.R`, with byte-exact inputs in
  `tests/rt/connections/data/`.
- Known gaps: the refusals above.
