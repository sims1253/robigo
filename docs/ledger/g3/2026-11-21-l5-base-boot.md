## 2026-11-21: base's boot from its database, beside M1's loader (L5, pulled forward)

- Why: base.rdb's L4 bar needs base's real values when makebasedb.R runs,
  which M1's lazy loader does not give (it wrote 1148 promises). GNU R's
  boot decides by what `R_HOME/library/base/R/base` is: base's whole
  source during the build, `baseloader.R` after base's database rule. One
  boot path, `R_ReplFile` of that file, covers both.
- What:
  - `stage0` (crates/robigo-rt/src/base.rs) binds names.c's primitives and
    internals robigo-rt lacks to the not-implemented builtins
    (`InitNames`: `browser`, `.primTrace`, `.primUntrace` and the rest are
    bound, their bodies E's), then `.Device`/`.Devices` (`InitGraphics`),
    then `R_ReplFile` of the base file and the system profile, as
    main.c's `setup_Rmainloop` orders them.
  - `ROBIGO_RT_BOOT=rdb` (crates/robigo-rtapi/src/main.rs) boots that way
    from the checkout's `.robigo/rt-home-db`; `stage0` keeps the source
    tree; unset is M1's loader, still the default.
  - `scripts/rt-home-db.sh`: the source tree copied, base's database rule
    (base/Makefile.in's `$(pkg).rdb`: makebasedb.R with
    `_R_COMPILE_PKGS_=1`, run by the given robigo-rt booted from the source
    base), then `baseloader.R` installed as the base file. Stamped with
    the source tree, the script and the binary; 24 s here.
  - The rt job (modes shard) makes the tree and runs
    `tests/boot_db.rs` after the R_HOME tree.
- Results, main 459478a2f + #860 + #916:
  - base.rdb written from the source boot against the oracle's
    (`scripts/rt-rdb-compare.sh`): the maps agree (1179 variables, 10
    references); records: 1152 the same bytes, 34 the same but for byte
    code (both sides compiled), 1 build path, 2 different (`.popath`, NA
    here; `.lib.loc` in env::6, empty here because the profile's
    `.libPaths()` stops in Sys.glob).
  - The boot from it: `ls(baseenv(), all.names = TRUE)` is GNU R's 1407
    names (unsorted, one, `reg.finalizer`, two places apart);
    `loadedNamespaces()` lacks `compiler`, which GNU R loads at boot with
    the JIT on (R_init_jit_enabled: after this, C1's side).
  - The system profile stops at three expressions (Sys.info, Sys.glob: E).
- Start-up, `--vanilla -e 1`, `R_DEFAULT_PACKAGES=NULL` (callgrind
