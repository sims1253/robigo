### The serializer finding (S1, the foreman's question)

Under the default boot (M1's loader) a save compiles every closure of
base again (`Writer::cmpfun1` → `jit::cmpfun1`, the writer's cache being
per save), because M1's closures are robigo-rt-compiled with no BCODESXP
body. Measured on 13c4694b3's binary, `saveRDS(as.list(baseenv()))` at a
load of about 35:

| boot | one save | two saves |
|---|---:|---:|
| default (M1 loader) | 18.4 s | 27.8 s |
| rdb | 0.14 s | 0.24 s |

Under the rdb boot base's closures come from base.rdb with their byte-code
bodies, so the write never compiles them. No fix here (the foreman's
ruling: a memo would be code that dies with the interim boot).

What it costs today: every save of base's closures under M1. In the tree,
A1's builtin-diff cases on `env.base` (`~/.cache/robigo-research/a1/env2list-timeouts.md`):
26-30 `env2list` ids and `eapply` id 341, which went from failing fast to
the case timeout. The harness saves each record with `saveRDS`; with
this branch's binary, `.Internal(env2list(baseenv(), TRUE, TRUE))`
(1407 bindings) takes 0.11 s and one `saveRDS` of it 10.1 s under M1,
against 0.04 s and 0.12 s under rdb, and `scripts/builtin-diff.py show
env2list 27` passes in 4.0 s under `ROBIGO_RT_BOOT=rdb` where under M1 it
had not ended after 300 s. No `tests/rt` case saves base's closures under
M1 today.

What ends it: L5's first item, the rdb boot the default for conformance,
perf-rt and builtin-diff (#942's list, item 3). In PRs from here: the
one-way tree build with the 13 script lows comes first in the foreman's
order, then the flip, so the flip is the second PR after this one; it
does not depend on the tree build, so it can be the next if the order is
swapped.

### User closures: compiled once per save, on either boot (C1's)

A closure robigo-rt's JIT compiled has no BCODESXP body, so each save
compiles it again (`Writer::cmpfun1`; its cache is per save), on the rdb
boot too. This does not die with L5: C1's V4 step 3 keeps the byte code.
Measured with this branch's binary, 100 `saveRDS(f)` of
`function(x, y = 2) { z <- x + y; if (z > 3) z * 2 else z - 1 }`
(load about 27):

| boot | f never called | f called 3 times (compiled) |
|---|---:|---:|
| default (M1 loader) | 0.046 s | 0.65-0.99 s |
| rdb | 0.043 s | 0.44-0.58 s |

About 0.45 ms a save for the closure itself, 4-10 ms for the compile it
repeats.
