# Source references in robigo-rt, S1: keep.source = TRUE (2026-11-23)

E. The scope was approved by the foreman with conditions; this entry records
the scope, what S1 does, what it measured, and what comes after it.

## GNU R 4.6.2's machinery

- **gram.y.** With `ParseState.keepSrcRefs` the parser makes
  `makeSrcref(lloc, srcfile)`: an INTSXP of 8 (first_line, first_byte,
  last_line, last_byte, first_col, last_col, first_parsed, last_parsed),
  class "srcref", its "srcfile" attribute the srcfile environment. It
  attaches them in three places:
  - a `function` call gets its srcref as a 4th element (xxdefun);
  - each `{` gets a "srcref" list (the brace's, then one per statement),
    "srcfile" and "wholeSrcref" (xxexprlist, attachSrcrefs);
  - the top-level expression vector gets "srcref", "srcfile" and
    "wholeSrcref" (R_Parse).
- **The position state** (xxgetc, gram.y:597). After each byte: `\n` gives
  line+1, column 0, byte 0, parsed+1; any other byte gives byte+1, and
  column+1 for an ASCII byte or a UTF-8 lead byte; a tab then sets the
  column to the next multiple of 8. StringValue and RawStringValue count a
  multibyte character's continuation bytes twice under an mbcs locale (the
  bytes are read, pushed back and read again), independently of
  known_to_be_utf8, which decides the column rule. `#line N "file"`
  (processLineDirective) sets the line to N, not the parsed line, and makes
  a "srcfilealias" environment under an environment srcfile.
- **source.c's do_parse.** An environment srcfile turns keepSrcRefs on.
  Base's `parse()` makes one (`srcfilecopy`) when `keep.source`.
- **The console (R_Parse1Buffer).** The code-generating parse of each
  statement reads `getOption("keep.source")`. When TRUE its srcfile is a new
  environment; if a srcref was attached it becomes a "srcfilecopy" with
  `filename` "" and `lines`, the console buffer as one string.
- **Printing.** A closure with a "srcref" prints its text when `useSource`
  (print's default): deparse's src2buff calls base R's
  `as.character.srcref`. `body()` drops the attributes.
- **Byte code.** cmp.R's MAKECLOSURE constant is `list(formals, body,
  srcref)`; eval.c:8158 sets any non-NULL third element as the closure's
  "srcref" attribute. With srcrefs the compiler also adds a `srcrefsIndex`
  constant.
- **Evaluation** (R_Srcref per `{` statement, in contexts; traceback "at
  #N", `show.error.locations`): S2.

## What S1 does

- `srcref.rs` ports xxgetc's position state, `#line` and makeSrcref, with
  unit tests for UTF-8 in three locales, tabs and the directive inside a
  string.
- `lower.rs` attaches srcrefs while lowering: a `function`'s 4th element, a
  `{`'s list. `lower_in` is generic over its source references (`Src`), so
  the lowering with keep.source = FALSE is its own instance, the code it
  was before: no argument, no tests.
- `reader.rs` and `source.rs`: `parse()` with an environment srcfile; the
  string bytes come from the lexer's tokens, so a failed parse has them up
  to its error too. A parse error names the srcfile: gram.y's getFilename
  for the classed conditions (the `#line` alias in effect included),
  source.c's getParseFilename for parseError()'s message.
- `options(keep.source = TRUE)` is accepted (options.c's checks), and the
  console keeps source references from the next statement on.
- The compiler takes the srcref'd `function`: Op::MkClosure's `b` is the
  srcref constant, set out of line in the VM (`closure_srcref`, cold).
  bctrans hands MAKECLOSURE's third element on as `b`, the pool's own
  object, so a cached translation reads it back by its pool path. C1's
  guards: the code.rs verifier, tcache's typed check, the crosscheck's role
  C for `b`.
- Printing a closure from its srcref, `deparse(control = "useSource")`, a
  `{`'s and the expression vector's srcrefs: deparse.rs evaluates
  `as.character(srcref)` in base at print and deparse time.

## Cases (recorded on 4.6.2)

- `tests/rt/srcref/`: parse-text, line-directive (with CRLF), print,
  inner (closures made in compiled code, cmpfun and the JIT), console
  (options in a script, sys.source), parse-error.
- `tests/bc-mutate/makeclosure-srcref.R`: MAKECLOSURE's third element as a
  srcref, another object, NULL and missing; its index past the pool.
- `crates/robigo-rtapi/tests`: the option accepted, R_KEEP_PKG_SOURCE with
  sys.source, the interactive console's transcript.
- A tree built with `R_KEEP_PKG_SOURCE=yes`: all 139 compiler functions keep
  their srcrefs and srcfilecopy environments through the lazy-load
  database; `make.codeBuf`'s 12 inner closures get srcrefs `identical()` to
  their pool constants, from cache hits and with the cache off alike; under
  `ROBIGO_TRANSLATION_CACHE=verify` 1,729 hits, none differing.

## The cost with keep.source = FALSE

The new runtime work is one option read per console statement, as GNU R
does. The branch was measured against main 8afcad0c6, each binary on trees
it built itself.

- **The four starts** (rt-startup.py; median of the layout shifts, then
  main's own spread across them):

  | start | main | S1 | change | main's spread |
  |---|---:|---:|---:|---:|
  | interim | 11,768,451 | 11,766,842 | −0.014% | 73,298 |
  | rdb-jit | 80,500,157 | 80,499,211 | −0.001% | 223,184 |
  | rdb-nojit | 45,531,729 | 45,574,409 | +0.094% | 130,122 |
  | rdb-nocache | 90,456,119 | 90,502,443 | +0.051% | 468,384 |

  rdb-nojit's +0.094% was this measurement's lead. Under callgrind with
  ASLR off it was +10,344 instructions, all in lowering: an
  `Option<&SrcCtx>` threaded through every node cost lowering 3%. With
  `lower_in` generic over `Src` the start is −1,485 (−0.003%).
- **The cold rows** (idiom-vs-r.py, instructions per iteration):
  runonce, toplevel-lines, do-call, eval-parse and map are within a few
  hundred instructions of main on both boots, with mixed signs.
  Repeated runs of one binary differ by as much (toplevel-lines on main:
  67,623 and 67,808). Callgrind's per-iteration inclusive costs settle it:
  lowering is the same instance (1,522.5 on both); `do_parse` is 168
  cheaper (9,083.7 to 8,915.8). source5k needs the utils namespace and
  runs on neither binary today.
- **The call and jit rows** (vm::run's MkClosure arm): plain, defaults,
  named, env-fn, superassign and s3 are identical. trycatch, lapply,
  vapply, sapply, mapply and Map are within ±0.07%, and the seven jit
  rows within −0.109% to +0.037%, mixed signs (they run cmp.R).
  vm::run is 0x7ac6 bytes against main's 0x7acf: the arm calls
  `mk_closure` (inlined) and sets the srcref in `closure_srcref` (cold,
  out of line, 0x282 bytes).

## Not in S1

- **S2:** srcrefs during evaluation (R_Srcref, contexts, traceback, error
  locations, `srcrefsIndex` in compiled code, which S1 ignores).
- **`#line` in parse errors**, a gap on main independent of srcrefs:
  parseError()'s message and the conditions' line numbers do not follow the
  directive (GNU R: `other.R:7:6`; robigo-rt: `<text>:3:6`).
- **The interim boot** bakes `keep.source` FALSE (options.rs), so its
  interactive console keeps none; the rdb boot runs Common.R's
  `options(keep.source = interactive())`. L's flip retires the interim boot.
- `source()` and `removeSource()` need the utils namespace.
- `keep.parse.data` and getParseData.
